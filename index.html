Import Monthly Contributions via CSV (Bulk / Historical)

Use this to load years of past monthly contributions in one go — one row per employee per month. Upload a CSV with the following columns (in order):

emp_id, name, month, szabist_contribution, employee_contribution, remarks

month must be in YYYY-MM format (e.g. 2010-07). The employee must already exist (import employees first) and is matched by emp_id — the name column is just there so the sheet is easier to read/check by eye; if it doesn't match the employee on record for that ID, you'll get a warning after import (the row still imports). Re-importing a row for an emp_id + month that already exists overwrites it, so you can safely re-upload a corrected file.

How Profit is Calculated

Profit is applied per Financial Year on the fund balance at the start of that FY.
Formula: Profit = Balance at FY Start × (Rate / 100)
FY periods are defined in Settings → Financial Year.
